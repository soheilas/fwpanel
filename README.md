## نصب (یک خط، **فقط روی سرور خارج**)

روی سرور خارج (Debian / Ubuntu) به‌عنوان root:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/soheilas/fwpanel/main/install.sh)
```

نصب‌کننده پنل را نصب می‌کند و **آدرس و رمز** را چاپ می‌کند. بعد می‌پرسد:

> **Set up an Iran server now? [y/N]**

اگر `y` بزنی فقط **آی‌پی و رمز root سرور ایران** را می‌خواهد؛ بقیه‌اش خودکار است: اتصال SSH، نصب پنل روی ایران،
پیدا کردن بهترین تونل (GRE6 ← GRE4 ← مستقیم) با **تست واقعی ترافیک**، بهینه‌سازی (MTU/MSS/کرنل)، اتصال همگام‌سازی و در پایان یک **خلاصه‌ی نهایی**.
رمز فقط همان لحظه در حافظه است، ذخیره نمی‌شود و دسترسی موقت SSH بعد از کار پاک می‌شود.

روی سرور ایران **هیچ‌چیز دستی نصب نمی‌کنی**. بعداً هم هر وقت خواستی سرور ایران اضافه کنی: دستور `fwpanel add-iran`
یا دکمه‌ی **«افزودن سرور ایران»** در خود پنل.

### SSH نداری یا نمی‌خواهی رمز بدهی؟ حالت یک‌خطی
در پنل: **افزودن سرور ایران ← دستور یک‌خطی**. پنل یک دستور کوتاه می‌دهد؛ آن را روی سرور ایران paste کن.
فایل نصب از سرور خارج برداشته می‌شود (GitHub لازم نیست)، فقط یک‌بار قابل دانلود است و بعد از نصب **خودش پاک می‌شود**.

## امکانات

| | |
|---|---|
| **فوروارد** | TCP، UDP یا هر دو · NAT قابل کنترل · روشن/خاموش · دائمی بعد از ریبوت |
| **ترافیک** | سرعت لحظه‌ای هر فوروارد و هر کارت شبکه + **مجموع ماندگار** با دکمه‌ی ریست |
| **چند سرور** | قانونی که روی سرور خارج می‌سازی، خودکار روی سرورهای ایران هم ساخته می‌شود |
| **تونل** | GRE6 (روی IPv6) و GRE4 (روی IPv4)؛ **تست سلامت**، **بهینه‌سازی** و **تعمیر با یک کلیک** |
| **امنیت** | لیست آی‌پی مجاز · محدودیت تلاش ورود · HTTPS اختیاری · همگام‌سازی امضاشده با HMAC |
| **سبک** | یک فایل پایتون بدون وابستگی · حدود ۱۵ مگابایت رم |

## تونل‌ها: تست، بهینه‌سازی، تعمیر

کارت **تونل‌ها** در پنل برای هر تونل وضعیت (سالم / ضعیف / قطع)، افت بسته، تأخیر و MTU را نشان می‌دهد.

- **تست:** پینگ واقعی از داخل تونل (افت بسته، تأخیر، جیتر) و بررسی مسیر بیرونی
- **بهینه‌سازی:** با پینگ‌های DF بزرگ‌ترین MTU واقعی مسیر پیدا می‌شود و `MTU تونل = MTU مسیر − سربار GRE` (GRE4: ۲۴، GRE6: ۴۴) ثبت می‌شود؛
  کلمپ MSS برای TCP روی تونل فعال می‌شود؛ تنظیمات کرنل (BBR، fq، بافرها، `rp_filter`، `ip_forward`) اعمال می‌شود
- **تعمیر:** اگر تونل افتاده، اینترفیس، آدرس، MTU، مسیر و سرویس systemd بررسی و درست می‌شود
- تونل‌ها دائمی‌اند (سرویس systemd) و بعد از ریبوت بالا می‌آیند

## مدیریت: دستور `fwpanel`

```
fwpanel                 منوی مدیریت
fwpanel add-iran        راه‌اندازی خودکار یک سرور ایران (SSH)
fwpanel info            آدرس، پورت، پروتکل
fwpanel status | log    وضعیت و لاگ
fwpanel start | stop | restart
fwpanel password        رمز جدید
fwpanel port [N]        تغییر پورت پنل
fwpanel tls on|off      HTTPS / HTTP
fwpanel allow-clear     حذف لیست آی‌پی مجاز (اگر قفل شدی)
fwpanel update          آپدیت به آخرین نسخه
fwpanel uninstall       حذف
```

تنظیمات (پورت، HTTP/HTTPS، آی‌پی مجاز، رمز، پشتیبان‌گیری) از داخل خود پنل هم قابل تغییر است:

![settings](docs/screenshots/settings.jpg)

بعد از راه‌اندازی، **قانون‌ها را فقط در پنل سرور خارج بساز**؛ روی سرورهای ایران خودکار ظاهر می‌شوند.
هر سرور ایران فقط از یک پنل خارج قانون می‌گیرد.

<details>
<summary>چطور کار می‌کند</summary>

```
کاربر ──► سرور ایران                            سرور خارج
          پورت X ──DNAT──► آی‌پی تونل:X ══GRE══► پورت X ──DNAT──► مقصد نهایی
                    ▲                                  │
                    └── همگام‌سازی HMAC (هر تغییر + هر ۵ دقیقه) ◄┘
```

درخواست‌های همگام‌سازی با HMAC-SHA256 و زمان‌سنج ۱۲۰ ثانیه‌ای امضا می‌شوند؛ کلید روی شبکه نمی‌رود و روی HTTP هم قابل جعل نیست
(فقط محتوای قانون‌ها خوانا می‌ماند).
</details>

<details>
<summary>امنیت و نکات</summary>

- رمز با PBKDF2 (۲۰۰ هزار تکرار)؛ کوکی `HttpOnly` + `SameSite=Strict`؛ هدر CSRF
- روی HTTP رمز و کوکی رمزنگاری نمی‌شوند؛ برای پنل بازِ اینترنتی **آی‌پی مجاز** بگذار یا HTTPS بزن. اگر رمز root سرور ایران را از داخل پنل روی HTTP وارد می‌کنی از شبکه‌ی امن استفاده کن (یا `fwpanel add-iran` در ترمینال)
- GRE4 به باز بودن پروتکل ۴۷ بین دو سرور نیاز دارد؛ اگر بسته باشد، نصب‌کننده خودش به حالت بعدی می‌رود
- بعضی دیتاسنترها آدرس‌های IPv6 خودکار (SLAAC، شامل `ff:fe`) را بلاک می‌کنند؛ آدرس ثابت ترجیح داده می‌شود
- پورت ۲۲، پورت‌های sshd و پورت خود پنل اجازه‌ی فوروارد ندارند
- مجموع ترافیک هر ۳۰ ثانیه ذخیره می‌شود
- پنل با root اجرا می‌شود (برای iptables) و فقط IPv4 فوروارد می‌کند
</details>
