افزودن سرور ایران

پنل با SSH وارد سرور ایران می‌شود و خودش همه‌چیز را انجام می‌دهد: نصب پنل، ساخت و آزمایش بهترین تونل، بهینه‌سازی MTU، لینک و همگام‌سازی. رمز فقط همین یک بار استفاده می‌شود و هیچ‌جا ذخیره نمی‌شود.

⚠ این پنل روی HTTP است و رمز SSH بدون رمزنگاری به پنل می‌رسد. بهتر است «نصب با یک دستور» را انتخاب کنی یا اول HTTPS را روشن کنی.

فایل و SSH لازم نیست: یک دستور کوتاه می‌گیری که روی سرور ایران می‌زنی. دستور ۳۰ دقیقه اعتبار دارد و یک‌بار مصرف است؛ بعد از نصب هیچ فایلی روی سرور ایران نمی‌ماند.
